# WFDP 2026 — Workshop on Field-Deployable Perception 2026

Working repository for the WFDP 2026 proceedings, presenter coordination and
registration desk.  The workshop is co-located with the 19th International
Conference on Field Robotics (ICFR 2026) and takes place on 14 December 2026.
